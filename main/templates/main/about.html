About KUIS

KUIS is a corpus-linguistics tool for an annotated Indonesian learner corpus. Its source texts are XML files in which each observed error is marked as a <segment> carrying a classification and, where one exists, a correction.

How analysis works

Corpora, not files. Every analysis runs over the corpora you select, never over a single file. A file may sit in several corpora; when selections overlap it is still counted once.

Two readings of the same text. Original counts the learner text as written. Corrected substitutes the correction recorded on each annotated segment. Files without annotations read the same in both modes.

Sequences stay within a file. Collocations, n-grams and concordance windows are collected per file, so a sequence is never invented across a boundary between two texts.

Counts are case-folded and tokenised on word characters. Frequencies are also reported per million tokens, so corpora of different sizes can be compared directly.
