The node is centred and the two contexts read outward from it — left context right-aligned, right context left-aligned — which is what makes a concordance scannable; the sorted side is set in full-strength ink so the eye knows which column carries the ordering. The two context columns are equal widths and the node column sits between them, so the node is the same distance from each context on every row whatever the term is — a phrase wraps inside its column rather than spilling over the contexts. A context that does not fit its column is clipped rather than wrapped, so the node column stays on one axis.
