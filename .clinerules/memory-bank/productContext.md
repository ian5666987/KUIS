# Product Context – TrainBuilder

## Target User

The primary user is a Workshop Supervisor working in a railway maintenance or preparation facility.
This user is not a software engineer and expects the system to guide them through a clear, linear workflow.

## User Intentions

- Describe a train configuration accurately
- Validate that the configuration is safe under expected conditions
- Understand results without deep technical knowledge
- Iterate quickly on what-if scenarios

## Problems Addressed

- Fragmented tooling for train modeling and validation
- Late detection of braking or mechanical issues
- Difficulty interpreting raw sensor data

## Value Provided

TrainBuilder acts as a decision support tool by combining modeling, computation, and visualization into a single coherent workflow.

## Success Criteria

- The user can complete the full scenario without technical assistance
- Results are consistent and reproducible
- The workflow matches real workshop reasoning
